AWM Public Product Information API Usage

楽天市場の公開商品情報を、社内での商品照合・カタログ確認・価格参照・商品分析に利用するための公開説明ページです。

AWM only uses publicly available Rakuten Ichiba product information. This page does not provide access to an AWM system, database, server, or API credential.

利用目的

公開商品情報をもとに、SKU 照合、商品情報の確認、価格参照および社内の商品分析を支援します。

AWM uses public product information for internal SKU matching, catalogue review, price reference and product analysis.

取得する情報

商品名、価格、店舗情報、レビュー情報、公開されている販売状態など、楽天市場で公開されている商品情報のみを対象とします。

Only public item details, such as titles, prices, shop information, review signals and public availability, are requested.

取得しない情報と安全管理

  • 店舗の非公開在庫数、注文情報、顧客情報、決済情報は、この公開 API 利用では取得しません。
  • API 認証情報は非公開の環境で管理し、この公開サイトやクライアント側のソースには掲載しません。
  • AWM のサーバーアドレス、データベース、バックアップ、ログ、運用データは公開しません。
  • API リクエストは、該当する楽天 Web Service の要件に合わせて、必要に応じたキャッシュとレート制限を行います。

Private inventory quantities, orders, customer data and payment data are not requested. Credentials and operational systems are not published. API requests are rate-limited and cached where appropriate.
